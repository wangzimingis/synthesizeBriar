# 2026-10-07

## 合成大奶娃 · 排行榜置顶改造

**需求**：把游戏排行榜改成「彭于晏 永远是第一名，分数取最大值」。

**项目结构**
- `合成大奶娃.html` —— 单页入口，脚本从 `合成大奶娃_files/` 加载（注意本地文件名带 `.下载` 后缀，浏览器仍能当 JS 执行）。
- `合成大奶娃_files/leaderboard.min.js.下载` —— 排行榜全部逻辑（提交/拉取/渲染）。
- `合成大奶娃_files/game.js.下载` —— 游戏主体，只在结束时调 `window.DanaiwaBoard.onGameOver(score)`，不参与榜单渲染。

**关键发现：榜单是远端共享库，不是本地数据**
- 该文件开头的 `_u()` 是按 `_K = [90,60,145,39]` 做 hex-pair XOR 的字符串混淆。
- 解码结果：接口 `https://tinywebdb.appinventor.space/api`，user `danaiwa`，secret `6f52518c`，key 前缀 `dnw_`，昵称存 localStorage 键 `danaiwa.name`，action 为 `update` / `search`。
- `MAX_SCORE = 99999999`；`WINDOW = 20`（只取最近 20 次提交）；`SCAN_PAGES = 2`。
- 远端榜上已存在 `t: 1.7976931348623157e+308` 的刷榜记录，环境比较脏。

**实现方案（本地置顶，未写入远端）**
在 `leaderboard.min.js.下载` 中新增：
- 常量 `PINNED_NAME='彭于晏'`、`PINNED_SCORE=MAX_SCORE`、`PINNED_TAG='__pinned__'`。
- `pinTop(rows)`：构造置顶记录插到 index 0，跳过同名条目，总行数截到 `WINDOW`。
- `fetchTop()` 末尾改为 `return pinTop(fresh);`
- `renderBoard()` 的 `is-mine` 判断加 `row.tag !== PINNED_TAG`，避免玩家刚好打出同分时置顶行被标成「我的」。

**验证方式（可复用）**
Node 起轻量 DOM 桩 + `vm.runInContext` 加载真实脚本，直接打真实接口跑 `DanaiwaBoard.fetchTop()`，实测 `ROW0 = {tag:'__pinned__', name:'彭于晏', score:99999999}`，总行数 20。

**环境坑**
- 本机 Git Bash 不可用（`ls`/`dirname` 都找不到），要用 PowerShell。
- PowerShell 工具不回显 stdout —— 需要把输出 `Set-Content` 到文件再读。
- `node --check` 不认 `.下载` 扩展名，得先复制成 `.js`。
- 沙箱内 `Remove-Item` 走 trash 且失败（SAFE_DELETE_FAIL_CLOSED），临时文件删不掉，只能留在 `.workbuddy/tmp/`。
